# TradingView Free Companion

Free TradingView-side companion for the BTC microstructure system.

This script uses TradingView OHLCV data. It does NOT import the Delta Exchange order-book feed.

Displays:
- fast flow
- slow CVD delta
- price return
- buy-volume share
- regime
- BUY/SELL confirmation markers
- alert conditions

Exact Delta Exchange microstructure remains in:
data/live_microstructure_state.json

Local dashboard:
http://127.0.0.1:8790

Live order execution remains disabled.
